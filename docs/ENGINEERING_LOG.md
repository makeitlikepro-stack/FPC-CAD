## 2026-10-31 — Stage 5 step 1: sketch model + constraint solver (Candidate)
- User decisions: own Pascal solver (not PlaneGCS), first core + Extrude (interactive editor later), any plane from the start.
- `src/sketch/cad.sketch.model.pas`: one number array (point x/y, circle radii) + fixed flags; entities line / circle / arc (arc = centre, start, end, CCW, automatic arc rule); 25 constraint kinds (coincident, horizontal/vertical (line or 2 points), distance, distance X/Y, length, point on line/circle, point-line distance, parallel, perpendicular, angle, collinear, equal length/radius, radius, diameter, tangent line-circle (side kept from the geometry), tangent circles (outside/inside chosen from the geometry), concentric, midpoint, symmetric); remove/edit constraint; plane (origin, X, normal -> orthonormal) and 2D -> 3D.
